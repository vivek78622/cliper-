Good to know.

What exactly am I buying?

A one-time ₹199 download with the merged tool source, complete master prompt and setup guide for live discovery, chat-scored highlights, vertical facecam clips, captions and scheduled publishing.

Is this a subscription?

No. The tool pack costs ₹199 once. It includes the integrated command-line source, setup guide and master prompt.

Will it automatically post videos?

No. This pack searches for streams, captures footage, scores highlight moments, and renders vertical clips. Scheduling uses the separately linked GTA Auto Sender and Zernio setup. Review each clip and follow the guide’s dry-run and account checks before scheduling.

Can it send automatic DMs?

Optional workflows can automate eligible Instagram inbox replies or comment-to-DM flows after you connect and authorize the account. This is for supported inbound conversations and user-triggered flows, not unsolicited bulk DMs. YouTube does not have a direct-message feature.

Does it detect the facecam automatically?

It detects a stable facecam near a frame edge and builds the top panel automatically. If the facecam or gameplay crop is unclear, the stacked render is skipped instead of exporting a misleading clip.

Does it use live chat?

Yes. Live chat reactions are the main highlight signal. When chat is unavailable or quiet, it falls back to audio and speech.

What do I need to set it up?

A local AI runner, YouTube Data API key, connected social accounts, scheduler credentials and permitted source footage. The guide explains setup, key storage, account IDs, testing and troubleshooting.
